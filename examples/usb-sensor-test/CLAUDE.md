# usb-sensor-test

This folder is a KiCad project run with the boardwright plugin. Use the `boardwright` skill for all work here.

- Project facts and the user's decisions: `PROJECT.md`. Read it first.
- Gate settings: `boardwright.json`. Reports: `reports/`. Datasheets: `datasheets/`. Release files: `fab/`.
- Keep the KiCad project files in this folder's root. Work only inside this folder.
- Never invent a part number, pin function or datasheet value; write "unverified".
- Never disable, waive or filter a check to make it pass. List proposed waivers for the user.
- Stop and show the report when a gate fails.
- Do not send, order or publish anything. Stop at the release files.
